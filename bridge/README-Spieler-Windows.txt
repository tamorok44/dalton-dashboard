DALTON DASHBOARD BRIDGE · Windows

Voraussetzung
-------------
Das WoW-AddOn "Dalton Dashboard Sync" ist über CurseForge installiert.
Für die Bridge brauchst du zusätzlich einen persönlichen Einrichtungscode von Christian.
Der Code ist 24 Stunden gültig und kann genau einmal verwendet werden.

Installation
------------
1. Diesen ZIP-Ordner vollständig entpacken.
2. "Installieren.cmd" per Doppelklick starten.
3. Falls Windows eine Sicherheitsabfrage zeigt, das Ausführen der von Christian erhaltenen Datei bestätigen.
4. Den persönlichen Einrichtungscode eingeben und Enter drücken.
5. Sobald "Dalton Dashboard Bridge ist eingerichtet" erscheint, ist die Installation fertig.

Bei einer unterbrochenen Installation den Installer erneut öffnen. Das Codefeld
leer lassen, um eine offene Kopplung fortzusetzen. Eine bestätigte Neukopplung
ersetzt den bisherigen Zugang dieser Installation.

Danach
------
Die Bridge startet künftig automatisch bei deiner Windows-Anmeldung und läuft ohne sichtbares Fenster im Hintergrund.
Nach /reload oder beim Ausloggen aus WoW werden freigegebene Dalton-Daten automatisch synchronisiert.
Du musst die Bridge nicht manuell starten.

Nach erfolgreicher Installation können dieses ZIP und der entpackte Download-Ordner gelöscht werden.

Deinstallation
--------------
Im Windows-Startmenü wird bei der Installation
"Dalton Dashboard Bridge deinstallieren" angelegt.
Dieser Eintrag widerruft zuerst den Gerätezugang und entfernt anschließend Bridge, Konfiguration und Autostart.
Falls der Widerruf nicht bestätigt werden kann, bleiben die Daten für einen
erneuten Versuch erhalten. Das WoW-AddOn selbst bleibt davon unberührt und kann separat über CurseForge entfernt werden.

Gold, Taschen und Bank gehören nicht zum Standard-Sync.
